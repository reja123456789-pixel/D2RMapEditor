📖 Manual

1. Get a map

  • 📚 Game maps… opens one of the game's own maps (search by name: forge, duriel, chaos…). Its HD file comes with it.
  • 🧩 Compose… builds a new map from a set's maze rooms: pick a room set, click grid cells on or off (or 🎲 Random maze), choose spawns, then Build map. Up to 121×121 tiles.
  • Open map… opens a .ds1 you saved before (select its .json too, if you have it).

2. Look around

  • Mouse wheel zooms, middle-drag or Space+drag pans. 🏰 Game view / 🗺 Grid view (V) switches the view.
  • Layers (left) shows or hides floors, walls, objects and HD pieces. Walkable in game: green = players walk there, red = blocked (walls, lava, cells with no floor).
  • The Cell panel (right) names every tile under the mouse and says if it is walkable in game.

3. Place monsters, objects and exits

  • Click 👹 Monsters & objects, pick a tab (Monsters, Objects, Exits) and an entry, then click the map. Right-click or Del deletes, drag moves.
  • Bosses & super uniques: every act's list also has all five act bosses. A monster from another act (or Act list set to another act) is added as a new monster row: the export lists the rows your mod must add.
  • Uber bosses (Uber Mephisto, Diablo, Baal, Lilith, Duriel, Izual, the Diablo Clone) are placed the same way, as new monster rows. 🧪 Untested in game: without the Uber Tristram scripts they may have no minions and drop no Hellfire Torch.
  • 🎲 Scatter spawn points puts champion packs and monster groups on walkable floor.
  • Exits lead to other levels; your mod links exit N with levels.txt VisN/WarpN. Waypoints don't travel in a new level.

4. Open up an area (optional)

  • 🧱 Remove walls (drag a box), then cover the opened cells with a 🟫 Floor stamp from a room of the same set, so HD shows floor there.

5. Export

  1. Export map + HD… checks the map (fix anything red) and Save map files… writes name.ds1, name.json (HD) and, for composed maps, name.pieces.json.
  2. In your mod: .ds1 → global\tiles\<folder>\, .json → hd\env\preset\<folder>\.
  3. Add the levels.txt and lvlprest.txt rows with the values the export shows. Its ready-made D2RMM mod.js block writes the lvlprest row correctly.

6. Put the map in the game with D2RMM

D2RMM (D2R Mod Manager) installs mods made of a mod.json, a mod.js and data files. A mod for one map, reached through a red portal you open with the Horadric Cube in Act 5:

  1. In D2RMM's mods folder make a folder, e.g. MyMap, with:
    • tiles\mymaps\mymap.ds1: the exported .ds1
    • hd\mymaps\mymap.json: the exported HD .json (same name and folder)
    • mod.json: { "name": "My Map", "description": "A new map", "version": "1.0" }
    • mod.js: the code below (Copy), with the values from Export map + HD… filled in at the top
  2. In D2RMM tick the mod, press Install, and start D2R through D2RMM (restart it after every install).
  3. In Harrogath put a Super Healing Potion in the cube and transmute: a red portal opens to your map.
mod.js
// One fixed map made with the D2R Map Editor, reached by a red portal from the cube in Act 5.
// Fill in MAP from the editor's export ("Map settings").
const MAP = {
    title: 'My Map',                 // the area name players see
    key: 'MyMapLevel',               // a unique name for the strings
    file: 'mymaps/mymap.ds1',        // under tiles\ in this mod
    sizeX: 24, sizeY: 24,            // export: SizeX / SizeY (the map's width-1, height-1)
    levelType: 35, pal: 3,           // export: LevelType / Pal
    dt1Mask: 4095,                   // export: Dt1Mask
    // export: the lvlprest.txt line (Populate, Logicals, Outdoors, Animate, KillEdge, FillBlanks)
    preset: { Populate: 1, Logicals: 0, Outdoors: 0, Animate: 1, KillEdge: 0, FillBlanks: 1 },
    cubeInput: 'hp5',                // what to put in the cube: a Super Healing Potion
};

// the map and its HD file
D2RMM.copyFile('tiles', 'global\\tiles', true);
D2RMM.copyFile('hd', 'hd\\env\\preset', true);

// levels.txt: a new Act 5 level, a copy of the Pit of Acheron's row made into a fixed map
const levels = D2RMM.readTsv('global\\excel\\levels.txt');
const id = Math.max(...levels.rows.map(r => Number(r.Id) || 0)) + 1;
const template = levels.rows.find(r => r.Name === 'Act 5 - Hell 2');
const level = {
    ...template,
    'Name': 'Act 5 - ' + MAP.title, 'Id': id,
    'DrlgType': 2,                   // a fixed map (a .ds1), not a random maze
    'LevelType': MAP.levelType, 'Pal': MAP.pal,
    'SizeX': MAP.sizeX, 'SizeY': MAP.sizeY, 'SizeX(N)': MAP.sizeX, 'SizeY(N)': MAP.sizeY,
    'SizeX(H)': MAP.sizeX, 'SizeY(H)': MAP.sizeY,
    'OffsetX': 80, 'OffsetY': 80,    // an empty spot in Act 5's world
    'Layer': 55, 'Position': 0, 'Waypoint': 255, 'QuestFlag': '', 'QuestFlagEx': '',
    'LevelName': MAP.key, 'LevelWarp': MAP.key + 'To', 'LevelEntry': MAP.key + 'Entering',
};
for (let n = 0; n !== 8; n++) { level['Vis' + n] = 0; level['Warp' + n] = -1; } // exits: link them here
levels.rows.push(level);
D2RMM.writeTsv('global\\excel\\levels.txt', levels);

// lvlprest.txt: the map file. Dt1Mask is the file's LAST column and D2RMM reads it as 'Dt1Mask\r'
// (Windows line ends): write it under that exact key, or no wall of the map blocks in game
const presets = D2RMM.readTsv('global\\excel\\lvlprest.txt');
const maskKey = Object.keys(presets.rows[0]).find(k => k.trim() === 'Dt1Mask');
presets.rows.push({
    'Name': 'Act 5 - ' + MAP.title, 'Def': Math.max(...presets.rows.map(r => Number(r.Def) || 0)) + 1,
    'LevelId': id, ...MAP.preset,
    'SizeX': 0, 'SizeY': 0, 'AutoMap': 0, 'Scan': 1, 'Pops': 0, 'PopPad': -4,
    'Files': 1, 'File1': MAP.file, 'File2': 0, 'File3': 0, 'File4': 0, 'File5': 0, 'File6': 0,
    [maskKey]: MAP.dt1Mask + (maskKey.endsWith('\r') ? '\r' : ''),
});
D2RMM.writeTsv('global\\excel\\lvlprest.txt', presets);

// the area name, in every language
const strings = D2RMM.readJson('local\\lng\\strings\\levels.json');
const LANGS = ['enUS', 'zhTW', 'deDE', 'esES', 'frFR', 'itIT', 'koKR', 'plPL', 'esMX', 'jaJP', 'ptBR', 'ruRU', 'zhCN'];
for (const [k, text] of [[MAP.key, MAP.title], [MAP.key + 'To', 'To ' + MAP.title], [MAP.key + 'Entering', 'Entering ' + MAP.title]]) {
    const s = { id: D2RMM.getNextStringID(), Key: k };
    LANGS.forEach(l => s[l] = text);
    strings.push(s);
}
D2RMM.writeJson('local\\lng\\strings\\levels.json', strings);

// the cube recipe: the item in MAP.cubeInput opens a red portal to the map
const cube = D2RMM.readTsv('global\\excel\\cubemain.txt');
cube.rows.push({
    'description': MAP.cubeInput + ' -> Portal to ' + MAP.title, 'enabled': 1, 'version': 100,
    'numinputs': 1, 'input 1': MAP.cubeInput, 'output': `"Red Portal,lvl=${id},qty=1"`, '*eol': 0,
});
D2RMM.writeTsv('global\\excel\\cubemain.txt', cube);
  • Monsters from other acts: add the monpreset.txt rows the export lists, in that order, before anything else adds rows to that act.
  • Exits to a second level: give each level its own row, and set VisN to the other level's Id and WarpN to an lvlwarp.txt exit type. An exit with no link crashes the game.
  • Check after Install, in mods\D2RMM\D2RMM.mpq\data\global\excel\lvlprest.txt: your row's last column must show the Dt1Mask.

Things that make or break a map in game

  • Dt1Mask is lvlprest.txt's last column: if a mod loses it, nothing blocks and players walk through every wall. After installing, check your row still shows it.
  • FillBlanks 1 when the map has cells with no floor (red in the overlay): otherwise monsters spawn there and players teleport in.
  • Map edges: game rooms are open where the next room would join. Close the map edges (Map panel, or the box in Compose) adds invisible walls there. It's optional.
  • Act bosses run quest code when they die, and may misbehave outside their own level. Keep maps at 121×121 or smaller: bigger ones crashed the game.
  • HD-safe: floors in D2R HD are 3D models, so tile painting and resizing are locked. Maps joined from rooms are proven in game for the River of Flame and the pygmy jungle; other sets show a warning until tested.

Game data

Start the editor with D2R Map Editor.exe (or Start Map Editor.cmd in the source version): it makes the game data from your D2R install the first time. After a game patch, run Update game data.cmd. The game data is Blizzard's: don't share the game folder or gamedata.js.
